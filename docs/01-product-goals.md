# Цели продукта

## Назначение

Проект создаёт автоматический ежемесячный Telegram-дайджест объявлений из городской группы «Объявления Гуардамар». Дайджест — это компактное оглавление объявлений за календарный месяц: каждая строка содержит короткий нейтральный заголовок и ведёт к конкретному исходному сообщению в Telegram.

Продукт не является поиском, каталогом по запросу, чат-ботом для участников или заменой основной группы. Его ценность — в эффекте общей витрины: человек просматривает весь выпуск и может заметить неожиданно интересное предложение.

## Цели

1. Автоматически собирать допустимые объявления в течение месяца.
2. Публиковать первого числа выпуск за предыдущий календарный месяц по времени `Europe/Madrid`.
3. Сохранять отдельную прямую ссылку на каждое исходное объявление.
4. Давать каждому объявлению короткий понятный заголовок и одну высокоуровневую категорию, выбранную для текущего выпуска.
5. Сохранять полноту выпуска: не объединять разные объявления и не отбрасывать их только ради сокращения текста.
6. Свести ручную работу к разбору спорных случаев и подтверждению публикации.
7. Сохранить анонимность личного аккаунта администратора: публикация выполняется ботом либо отдельным публичным механизмом проекта.
8. Работать на слабом Android-телефоне в Termux без тяжёлой локальной инфраструктуры.
9. Делать строки витринными: короткими, различимыми внутри категории и читаемыми в одну строку на мобильном устройстве, когда это возможно.

## Пользовательская ценность

- Участник быстро находит ранее опубликованное объявление через короткий заголовок и прямую ссылку.
- Участник открывает для себя услуги, товары, события и предложения, которые специально не искал.
- Автор получает дополнительную видимость своего объявления без отдельной оплаты и без ручной работы администратора.
- Группа демонстрирует активность и создаёт понятную точку входа для новых участников.

## Границы продукта

### Входит в первую версию

- Сбор сообщений основной группы.
- Использование существующей модерации и дедупликации как источника истины.
- Подготовка текста для LLM, классификация и генерация короткого заголовка.
- Каскад бесплатных LLM-провайдеров и локальный fallback без LLM.
- Предпросмотр и разбор спорных записей в личном чате администратора.
- Автоматическая разбивка на несколько Telegram-сообщений.
- Идемпотентная публикация в основную группу.

### Не входит в первую версию

- Поиск объявлений для участников через бота.
- Обязательные теги, Telegram Topics, анкеты публикации и Mini App.
- Локальный запуск большой модели на телефоне.
- Автоматическая публикация в чужих группах без явного разрешения их владельцев.
- Автоматизация личного Telegram-аккаунта администратора (userbot).
- Субъективный отбор «самых интересных» объявлений.

## Принципы решений

1. **Одна строка — одно объявление.** Несколько объявлений нельзя заменять сводной строкой.
2. **Прямая ссылка обязательна.** Если для записи нельзя получить корректную ссылку, она не публикуется автоматически и отправляется на проверку.
3. **Модерация первична.** Дайджест не должен противоречить существующей системе одобрения, удаления и дедупликации.
4. **ИИ не является единственной точкой отказа.** Его результат кэшируется; при сбоях есть резервный бесплатный провайдер и детерминированный fallback.
5. **Простота важнее инфраструктуры.** Для одного телефона используются Python, SQLite и long polling вместо Docker, PostgreSQL, Redis и webhook.
6. **Человек проверяет исключения, а не весь месяц.** Ручной интерфейс предназначен для сомнительных записей и ручных правок.
7. **Приватность по умолчанию.** Дайджест не извлекает контакты и цены в заголовок; они остаются в оригинальном сообщении.
8. **Категория не дублируется.** Заголовок строки добавляет различающую информацию, а не повторяет смысл заголовка раздела.
9. **Гуардамар подразумевается.** Город указывается в строке, только когда предмет объявления находится вне Гуардамара либо география существенно важна.
10. **Широкие разделы, конкретные строки.** Категории формируются по составу объявлений текущего месяца, оставаясь абстрактными; детали раскрываются заголовком объявления.
11. **Витрина, а не архив.** Бренд группы виден первым, а строка содержит предмет и наиболее привлекательное фактическое отличие без рекламных эпитетов.

## Формат выпуска

```text
📚 Объявления Гуардамар
Главное за сентябрь 2026 · Часть 1 из N

🏠 Недвижимость
• Квартира, 2 спальни ↗
• Семья ищет дом/таунхаус ↗

🚗 Транспорт и попутный груз
• Груз Аликанте → Валенсия ↗
```

Кликабельный маркер `↗` в конце каждой строки ведёт на оригинальное сообщение. В последней части используется ненавязчивое примечание: «Актуальность уточняйте у автора.»

У каждого выпуска обязательны:

- **хидер** в первой части: «📚 Объявления Гуардамар», строка «Главное за <месяц год>» и навигация части;
- **краткий хидер** в последующих частях: «📚 Объявления Гуардамар · <месяц год>» и `Часть X из N`;
- **футер** в последней части: краткое пояснение об актуальности и кликабельный призыв «Новые объявления каждый день → Объявления Гуардамар».

## Внешнее распространение

Основной выпуск публикуется в собственной группе. Для внешних групп допустимы только законные режимы:

- бот добавлен и получил право писать с явного согласия владельца группы;
- бот готовит выпуск, а владелец внешней группы публикует его вручную;
- бот публикует в закрытый служебный или публичный канал проекта, откуда выпуск пересылают вручную.

Внешний шаблон может быть компактнее, но не должен скрывать, что ссылки ведут в другую группу. Личные аккаунты администратора для автоматизации не используются.
