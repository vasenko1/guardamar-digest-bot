# Критерии готовности и приёмки

## Критерий готовности MVP

MVP готов, когда бот может без ручной сборки создать и опубликовать корректный месячный дайджест из принятых объявлений основной группы, а администратор проверяет только исключения.

## Функциональные критерии

### Сбор и хранение

- [ ] Новое сообщение основной группы сохраняется в SQLite с `chat_id`, `message_id`, временем, text/caption, типом медиа и статусом модерации.
- [ ] При редактировании сообщения обновляется сохранённая версия и запись помечается для повторной обработки.
- [ ] Альбом обрабатывается как одно объявление.
- [ ] Сообщение без текста и caption не получает выдуманный заголовок и попадает в проверку.
- [ ] Удаление ботом или подключённой модерацией исключает запись из будущего выпуска.
- [ ] Ссылка на исходное сообщение сохраняется вместе с исходными данными, до LLM-обработки.
- [ ] Импорт Telegram Desktop JSON загружает историю выбранного периода в те же таблицы, что и live-сборщик.
- [ ] Повторный импорт не создаёт дубликаты по `(chat_id, message_id)`.
- [ ] После импорта объявления проходят обычные правила, дедупликацию и обработку LLM.
- [ ] При обнаружении потенциального пропуска сообщений перед публикацией появляется техническое предупреждение для администратора.

### Классификация и заголовки

- [ ] Сервисные сообщения, команды, ответы без самостоятельного смысла и отклонённые модерацией записи не отправляются в LLM.
- [ ] Для новой подготовленной записи сохраняется категория, короткий заголовок, confidence и источник результата.
- [ ] Для каждого выпуска формируется отдельный список категорий, покрывающий реальные объявления этого месяца.
- [ ] В следующий месяц категории могут измениться без изменения уже опубликованного выпуска.
- [ ] Не создаются микрокатегории по типу сделки, городу, услуге или предмету объявления.
- [ ] Заголовок сохраняет намерение и не содержит телефон, цену или рекламные эпитеты.
- [ ] Явный запрос не превращается в предложение; число спален не подменяется числом комнат.
- [ ] Заголовок не заканчивается предлогом или союзом и не содержит скидки, акции либо подарок.
- [ ] Заголовок не повторяет смысл названия текущей категории.
- [ ] Заголовок указывает город, если предмет объявления находится вне Гуардамара, и не добавляет «Гуардамар» без необходимости.
- [ ] Для нескольких предметов в одном объявлении выбраны главные отличительные признаки без выдумывания фактов.
- [ ] Внутри одной категории нет буквальных одинаковых заголовков, кроме случаев, отмеченных для ручной проверки.
- [ ] Небольшой тематический раздел объединяется с близкой широкой категорией, если самостоятельный раздел ухудшает обзор выпуска.
- [ ] Ручной заголовок и ручная категория не перезаписываются автоматической обработкой.
- [ ] Одинаковый подготовленный текст не отправляется в LLM повторно без причины.
- [ ] Новое редакционное правило повторно обрабатывает только нарушившие его checkpoints.

### Каскад бесплатных моделей

- [ ] При ошибке основной бесплатной модели запрос автоматически передаётся резервной модели.
- [ ] Некорректный ответ модели не попадает в базу как корректный результат.
- [ ] При недоступности обеих моделей арбитраж дублей завершается локальным
  fallback; классификация сохраняет прогресс и безопасно блокирует выпуск до
  повторного запуска.
- [ ] Ошибка, переключение провайдера и fallback фиксируются в журнале.

### Состав выпуска

- [ ] В выпуск попадают только записи предыдущего календарного месяца в `Europe/Madrid`.
- [ ] Каждое включённое объявление представлено отдельной строкой; несколько сообщений не объединяются в одну сводку.
- [ ] Дубли, удалённые действующей системой модерации, не публикуются.
- [ ] Каждая строка содержит рабочую прямую ссылку на конкретное исходное сообщение.
- [ ] Ссылка показана последним элементом строки в виде кликабельного `↗`.
- [ ] Запись без валидной ссылки не публикуется автоматически и показывается администратору.
- [ ] После создания snapshot изменение исходного объявления не меняет уже сформированный выпуск.

### Вёрстка и отправка

- [ ] Все части укладываются в безопасный лимит Telegram.
- [ ] Для типовых русскоязычных строк заголовок и маркер ссылки по возможности укладываются в одну строку iPhone 8, но существенные факты не удаляются только ради этого.
- [ ] Первая часть начинается с бренда «📚 Объявления Гуардамар», месяца и навигации.
- [ ] Каждая последующая часть содержит компактный хидер с номером части.
- [ ] Последняя часть содержит футер «Актуальность уточняйте у автора.» и кликабельный призыв подписаться на группу.
- [ ] HTML экранирован; ссылка и строка объявления не разрываются между частями.
- [ ] Заголовок категории не остаётся в конце части без объявления.
- [ ] Продолженная категория явно помечена как продолжение.
- [ ] Каждая часть содержит имя выпуска и навигацию `Часть X из N`.
- [ ] Части публикуются в правильном порядке.
- [ ] При ошибке отправки повторная команда отправляет только отсутствующие части.
- [ ] Повторный запуск не создаёт дубликат уже опубликованного выпуска.

### Административный UX

- [ ] Неавторизованный пользователь не может открыть preview, изменить запись или опубликовать выпуск.
- [ ] Администратор может открыть preview, включить или исключить запись, изменить заголовок и категорию.
- [ ] Администратор может открыть исходное сообщение из карточки проверки.
- [ ] Интерфейс не обязан показывать итоговые числовые показатели выпуска.

## Эксплуатационные критерии для Termux

- [ ] Бот запускается отдельными документированными командами импорта, preview и публикации в Termux.
- [ ] MVP не требует автозапуска или постоянно работающего процесса.
- [ ] SQLite работает в WAL-режиме и резервная копия создаётся по расписанию.
- [ ] Работа бота не требует постоянно запущенного локального LLM-сервера.
- [ ] При временном отсутствии сети импортированные данные и состояние публикации не теряются.
- [ ] В журналах нет токенов Telegram и ключей LLM.

## Тестовые сценарии перед запуском

- [ ] Русское, украинское, испанское и английское объявление получают понятные заголовки.
- [ ] Объявление с фото и caption включается корректно.
- [ ] Альбом не создаёт несколько строк.
- [ ] Длинный заголовок сокращается или направляется на проверку.
- [ ] Одна очень большая категория корректно разбивается между частями.
- [ ] В выпуске корректно отображаются HTML-символы, emoji и ссылки.
- [ ] Сбой основной LLM активирует резервную.
- [ ] Сбой обеих LLM не отменяет выпуск остальных допустимых записей.
- [ ] Сбой Telegram после отправки одной части не приводит к повторной отправке этой части.
- [ ] Запуск на границе месяца, в феврале и при переходе летнего времени выбирает правильный период.

## Условия перехода к внешним группам

- [ ] Для каждого внешнего чата в настройках зафиксировано разрешение его владельца.
- [ ] Используется отдельный шаблон назначения и допустимый лимит частей.
- [ ] Публикация во внешнюю группу не использует личный аккаунт администратора.
- [ ] При отсутствии разрешения выпуск только готовится для ручной пересылки в служебный канал/чат.
